# Strategy 1: Top 3 Stocks – 5 Trading Days

## 1. Strategy Overview

The first trading strategy is based exclusively on the Stock Outperformance Prediction model.

The strategy uses the predicted outperformance probabilities generated by the selected Decision Tree Classifier to rank the selected Canadian stocks and identify the three most promising stocks on each trading day.

Unlike the second strategy, this approach does not incorporate market regime predictions or economic market classification signals. It relies entirely on the stock-level model predictions.

## 2. Stock Selection

For each trading day, all available stocks are ranked in descending order according to their predicted probabilities (Stock_Outperformance_Prob).

The three stocks with the highest probabilities are selected for investment.

When multiple stocks have identical probabilities, Close_Momentum_5D is used as a secondary sorting criterion to resolve ties.

This ensures that exactly three stocks are selected per eligible trading day.

## 3. Investment Parameters

The strategy uses the following fixed parameters:

| Parameter                  | Value          |
| -------------------------- | -------------- |
| Number of Selected Stocks  | 3              |
| Investment per Stock       | \$100          |
| Holding Period             | 5 Trading Days |
| Round-Trip Transaction Fee | 0.2%           |
| Investment per Trading Day | \$300          |

Each selected stock receives an equal investment allocation of \$100.

Positions are held for five trading days before their returns are realized.

## 3. Configurable Strategy Parameters

The strategy is controlled by four configurable parameters:

| Parameter          | Default Value | Description                                            |
| ------------------ | ------------- | ------------------------------------------------------ |
| INITIAL_INVESTMENT | 100           | Investment amount allocated to each selected stock.    |
| TOP_N              | 3             | Number of top-ranked stocks selected each trading day. |
| HOLDING_DAYS       | 5             | Number of trading days each position is held.          |
| ROUND_TRIP_FEE     | 0.002 (0.2%)  | Total transaction fee applied to each completed trade. |

These parameters are adjustable, allowing the strategy to be tested under different investment allocations, stock selection sizes, holding periods, and transaction cost assumptions.

Changing these values makes it possible to evaluate how different trading configurations affect profitability, risk exposure, and required capital.

**Note:** Changing HOLDING_DAYS also requires recalculating the corresponding future return target and exit dates to maintain consistency between the prediction horizon and the trading simulation.

## 5. Profit and Transaction Cost Calculation

The gross profit for each trade is calculated using the stock's actual five-day future return:

Gross Profit = Investment × (Future Return / 100)

Transaction fees are calculated as:

Fees = Investment × Round-Trip Fee

Net Profit is then calculated as:

Net Profit = Gross Profit − Fees

This approach accounts for transaction costs when evaluating the profitability of individual trades.

## 6. Capital Requirements

Since the strategy opens three positions per trading day and holds each position for five trading days, multiple positions may remain open simultaneously.

The maximum number of concurrent open positions is used to estimate the required trading capital.

The simulation assumes a fixed investment of \$100 per position.

## 7. Performance Evaluation

The strategy is evaluated using the following indicators:

- Total Number of Trades.
- Total Net Profit.
- Win Rate.
- Average Net Profit per Trade.
- Maximum Open Positions.
- Required Capital.
- Total Return.
- Compound Annual Growth Rate (CAGR).

These metrics provide an overview of the strategy's profitability, trading activity, and capital requirements.

## 8. Strategy Results

The initial simulation produced the following results:

| Metric                       | Result     |
| ---------------------------- | ---------- |
| Total Trades                 | 4,044      |
| Total Net Profit             | \$184.94   |
| Win Rate                     | 53.09%     |
| Average Net Profit per Trade | \$0.0457   |
| Maximum Open Positions       | 15         |
| Required Capital             | \$1,500    |
| Testing Period               | 5.39 Years |
| Total Return                 | 12.33%     |
| CAGR                         | 2.18%      |

The testing period extended from June 17, 2021, to November 6, 2026.

## 9. Conclusion

Strategy 1 provides a baseline stock-selection approach using the Decision Tree model's predicted outperformance probabilities.

The simulation generated a positive net profit over the testing period, with a win rate slightly above 50%.

However, the resulting CAGR of 2.18% indicates relatively modest annualized performance compared with the required capital.

This strategy serves as the baseline for comparison with Strategy 2, which incorporates market regime predictions to investigate whether additional market-level information can improve trading performance.

## Strategy 1: Top 3 Stocks – 5 Trading Days

This strategy uses the Decision Tree stock classification model to select the three stocks with the highest predicted outperformance probabilities each trading day. It operates independently of the Market Regime Prediction model.

Each selected stock receives a fixed investment of \$100 and is held for five trading days, with a round-trip transaction fee of 0.2%. When predicted probabilities are tied, Close_Momentum_5D is used as a secondary ranking criterion.

The simulation generated 4,044 trades, achieving a total net profit of \$184.94 and a win rate of 53.09%. The maximum number of concurrent open positions was 15, requiring an estimated capital of \$1,500.

Over the testing period from June 2021 to November 2026, the strategy achieved a total return of 12.33% and a CAGR of 2.18%.

These results establish the baseline performance for comparison with the second strategy, which incorporates market regime predictions.

### Configurable Parameters

The strategy uses four adjustable parameters: INITIAL_INVESTMENT (\$100 per stock), TOP_N (3 selected stocks), HOLDING_DAYS (5 trading days), and ROUND_TRIP_FEE (0.2%).

These values represent the default configuration rather than fixed constraints and can be modified to experiment with different trading scenarios. Any change to the holding period also requires updating the corresponding future return calculations and exit dates.
